## POS Print on DigiTax Dashboard

These are the steps required to run POS Print on the Sales and Credit Note invoices:

1. Download and install [QZ tray](https://qz.io/download/) (Version 2.1.2)

* Install Java
* Allow for browser and printer.

2. Watch this video for the details:

Windows: [VIDEO LINK](https://www.youtube.com/watch?v=qV6g9nEO3zE\&ab_channel=QZIndustries%2CLLC) (This is the default link added)

Linux: [VIDEO LINK](https://youtu.be/QlCAVQyjuU8?si=6Ssni6i6SnPL0TWl)

MacOS: [VIDEO LINK](https://youtu.be/jghL1PDukME?si=Wmlefq2J9OXVK-mY)

Please note:

1. Confirm that your printer is visible from the “Printers and Scanners” section of settings
2. Edit the printer’s description to be "**Thermal Printer CAYSN**" (That’s what DigiTax POS Print function references)

After doing this, click on POS Print and Click “Accept” on the two dialog boxes that will appear. There’s no need to worry with these dialogue boxes (You might need to always click on “Accept” every time you do a POS Print)
